# Architecture Overview

## Context

Lumina Studio is being rewritten from Python/Gradio to React + FastAPI.

**Target**: Localhost web app — FastAPI serves the UI on port 7860, pystray tray unchanged.
**Strategy**: Clean cutover — `ui/` and Gradio are deleted once the new stack is working.
**Hard constraint**: `core/`, `utils/`, `config.py` are never modified.

## Key Design Decisions

### 1. Core layer stays untouched
All image processing, mesh generation, color matching, and LUT logic lives in `core/` and `utils/`. The backend wraps these via thin adapters — no business logic is re-implemented.

### 2. Adapter layer isolates the Gradio dependency
`core/converter.py` imports `gradio as gr`. The adapter installs a stub `gr` module via `sys.modules['gradio']` before importing it, so `core/` never needs to change. See [backend.md](backend.md) for details.

### 3. In-memory session store
Large numpy arrays (the preview cache) live in a plain Python `dict` on the server, keyed by `session_id`. No Redis or database needed — this is a single-user local tool. Sessions expire after 2 hours of inactivity.

### 4. In-process job queue
Long-running operations (K-Means, mesh generation, calibration) run in a `ThreadPoolExecutor`. The frontend polls `GET /api/*/job-status/{job_id}` every second. No Celery, no Redis.

### 5. Type safety across the boundary
FastAPI auto-generates an OpenAPI schema at `/openapi.json`. `@hey-api/openapi-ts` consumes it and generates TypeScript types and Axios service functions into `frontend/src/api/generated/`. Run `yarn generate-api` after any endpoint change.

### 6. Monorepo with single start command
A root `package.json` uses `yarn workspaces` and `concurrently` to start both the backend and frontend with `yarn dev`.

## Migration Boundary

### Untouched
```
core/          utils/         config.py
lut-npy预设/   output/        assets/        tests/
```

### Modified (minimally)
```
main.py        ← remove Gradio launch, add uvicorn.run(); keep tray + port logic
requirements.txt ← remove gradio; add fastapi, uvicorn[standard], aiofiles
```

### Deleted after migration
```
ui/layout_new.py        (→ 30+ focused React components)
ui/callbacks.py         (→ typed FastAPI endpoint handlers)
ui/crop_extension.py    (→ react-cropper component, ~50 lines)
ui/palette_extension.py (→ PaletteGrid + LutColorGrid React components)
ui/styles.py            (→ SCSS modules)
```

## Verification Checklist

1. `GET /api/lut/list` returns the bundled LUT presets
2. Upload a PNG → `POST /api/converter/upload-image` returns a `session_id`
3. `POST /api/converter/generate-preview` → poll job → preview PNG renders in browser
4. Apply a color replacement → preview updates without re-running K-Means
5. `POST /api/converter/generate-3mf` → poll → download `.3mf` opens in Bambu Studio
6. `POST /api/calibration/generate` → download calibration `.3mf`
7. Full extractor flow: upload photo → mark 4 corners → extract → new LUT appears in `/api/lut/list`
